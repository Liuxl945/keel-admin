# 前端转全栈：我用 Node + Vue 写了一个能在线配表单的后台基座

我是前端，平时 Vue 写得多。去年想认真补一补后端，跟着教程把 CRUD 敲完，发现还是不会做真实项目：登录态怎么续、权限怎么落到按钮、事务和部署怎么弄，教程基本一笔带过。

后来干脆给自己找了个题目：把后台项目里那些每次都重写的部分做成一个基座，再在上面加一层在线配置表单的能力。做完之后，Node 这条链路算是走了一遍，也给自己留了个能直接开工的模板。

项目叫 Keel（龙骨），意思是船的脊梁，所有结构都围着它造。

地址先放这儿，感兴趣可以直接进去点：

- 演示：<http://8.148.233.130:8092/>
- 账号：`demo` / `Demo@123456`（登录页有一键填入）

## 技术栈

- server：Node.js + Express + TypeORM + PostgreSQL
- admin：Vue 3 + TypeScript + Element Plus
- app：uni-app，顺手做的适老化端

选型没什么讲究，就是按自己顺手的来。Express 简单，遇到问题好搜；TypeORM 的实体写法对前端来说不算陌生；前端还是 Vue，省得同时学两套东西。

## 它不是通用的低代码平台

我只想解决一件事：表建好之后，把表单、列表、查询条件和菜单权限配出来，能直接增删改查。

配完可以生成前后端代码，但不会自动写进项目，需要自己 review 后接进去。我把它当起点用，不当黑盒用。

## 建议怎么玩

1. 用 demo 登录，左侧进「在线开发 → 表单设计」，打开「采购订单」。这个表单有主表、明细子表、图片和文件上传、关联客户，比较接近实际项目里的单据页面。
2. 点「预览」。查询、分页、新增、编辑、删除都是真的在读写演示库，新增时加两行明细再保存，能看到主从表一起落库。
3. 回到「数据接口」，找「客户模糊查询」点「试运行」，输入关键字，能看到绑定后的 SQL 和参数。SQL 走模板加参数绑定，表和列走白名单，这是我做后端时花心思最多的一块。
4. 如果对生成的代码感兴趣，在表单列表点「代码」，可以看前后端文件，也能打包下载。

## 一些实话

- 写得最痛苦的不是页面，是权限、迁移、日志脱敏和部署。前端转全栈，难的都在这些不显眼的地方。
- 低代码只覆盖常规 CRUD，复杂业务还是要写代码。目标是省掉重复劳动，不是消灭开发。
- 数据接口目前只能在线调试，对外开放的运行时 API 还没做；字段类型也只支持常见的七种。
